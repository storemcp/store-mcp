# StoreMCP — wordpress.org assets

Solid-colour PNG placeholders at the exact dimensions wordpress.org expects.
Replace each file with real artwork before submitting to the directory.

| File | Size | Purpose |
| --- | --- | --- |
| `banner-772x250.png` | 772×250 | Small directory banner. |
| `banner-1544x500.png` | 1544×500 | Retina banner. |
| `icon-128x128.png` | 128×128 | Directory icon. |
| `icon-256x256.png` | 256×256 | Retina icon. |
| `screenshot-1.png` | 1280×720 | Dashboard. |
| `screenshot-2.png` | 1280×720 | Settings. |
| `screenshot-3.png` | 1280×720 | Tools. |
| `screenshot-4.png` | 1280×720 | Activity log. |
| `screenshot-5.png` | 1280×720 | License. |

The wordpress.org plugin handbook describes the banner / icon workflow here:
https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/

Screenshots referenced in `readme.txt` with matching captions:

1. Dashboard — live stats, quick-setup guide and endpoint copy.
2. Settings — API keys, rate limits, CORS, log retention.
3. Tools — per-module toggles with FREE/PRO badges.
4. Activity log — filters, expandable params, CSV export.
5. License — activation and pricing overview.
